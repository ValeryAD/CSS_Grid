Шпаргалка по CSS Grid

Все grid-свойства и функции, которые прошли за 7 уроков курса «Изучаем CSS Grid». Удерживайте под рукой, когда пишите макеты руками.

Свойство / функцияОписание
display: gridВключает grid-контейнер (урок 1)
grid-template-columnsОпределяет колонки (урок 1)
grid-template-rowsОпределяет строки (урок 2)
grid-templateСокращение: строки + колонки одной строкой (урок 2)
grid-template-areasИменованные области — макет без номеров линий (урок 2)
grid-areaНазначает элемент именованной области (урок 2)
grid-column / grid-rowЯвная позиция по линиям, span (урок 3)
gap (column-gap, row-gap)Отступы между треками
justify-items / align-itemsВыравнивание элементов в ячейках (урок 4)
justify-self / align-selfВыравнивание одного элемента-«бунтаря» (урок 4)
justify-content / align-contentВыравнивание всей сетки треков в контейнере (урок 4)
place-items / place-self / place-contentСокращения: align + justify в одном (урок 4)
margin: autoАвто-отступы: центрирует элемент в ячейке (урок 4)
grid-auto-rows / grid-auto-columnsРазмер неявных треков (урок 5)
grid-auto-flowНаправление авто-размещения: row / column + dense (урок 5)
orderПерестановка элементов без изменения HTML (урок 5)
repeat()Повтор трека: repeat(3, 1fr), repeat(auto-fit, …) (уроки 1, 7)
frДоля свободного места (урок 1)
minmax(min, max)Трек с диапазоном: «гибкость с полом» (урок 7)
auto-fitСоздать влезает сколько треков, пустые схлопнуть (урок 7)
auto-fillТо же, но пустые треки сохранить (урок 7)
clamp(min, val, max)Значение в коридоре — флюидная типографика (урок 7)
min() / max()Ограничение значения с одной стороны (урок 7)
min-width: 0 (+ overflow: hidden)Лечит «раздувание» ячеек длинными строками (урок 6)
🎓 Главная формула курса: каркас страницы — grid-template с minmax(), наполнение — repeat(auto-fit, minmax(…)) — и макет адаптивен без единой @media.
