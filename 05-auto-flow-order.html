Порядок и авто-размещение

Урок 5: как браузер сам расставляет элементы — неявные строки и колонки (grid-auto-rows), направление потока (grid-auto-flow), перестановка через order и заполнение «дыр» (dense)

1Авто-размещение и неявные строки

Пока вы не задаёте элементам явную позицию (урок 3), браузер сам «ставит их по порядку»: слева направо, строка за строкой. Если элементов больше, чем поместится в объявленные строки, Grid сам создаёт новые — неявные (implicit). Их размер задаётся через grid-auto-rows (и grid-auto-columns для неявных колонок): 

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 52px;   /* одна ЯВНАЯ строка */
  grid-auto-rows: 52px;      /* все НЕЯВНЫЕ строки — 52px */
  gap: 8px;
}

/* 7 элементов → 1-я строка явная, 2-я и 3-я неявные */

💡 Правило: объявили количество строк/колонок — подумайте и о размере неявных. grid-template-rows: repeat(2, 1fr) + grid-auto-rows: 1fr — классика «все строки одинаковые».

2Направление: grid-auto-flow: row | column

По умолчанию элементы идут по строкам (row flow). Свойство grid-auto-flow позволяет развернуть поток по колонкам — элементы будут идти сверху вниз, колонка за колонкой. Неявными становятся уже колонки: 

.grid {
  display: grid;
  grid-template-rows: repeat(3, 52px); /* явные строки */
  grid-auto-flow: column;      /* расставлять по колонкам */
  grid-auto-columns: 1fr;     /* размер неявных колонок */
  gap: 8px;
}

/* 8 элементов: 1-я и 2-я колонки явные (по 3 элемента), 3-я — неявная */

⚠️ В column-flow явными считаются строки (grid-template-rows), а неявными — колонки. Это частая путаница: grid-template-columns здесь почти не нужен.

3Перестановка элементов: order

Как и в Flexbox, order меняет порядок авто-размещения: элемент с меньшим order ставится раньше. Это удобно, когда порядок в HTML важен для семантики/доступности, а визуально нужен другой: 

/* исходный порядок в HTML: A B C D E F */
.c { order: -1; }   /* C — первым → C A B D E F */
.f { order: 20; }   /* F — в самый конец (по умолчанию 0) */

/* у элемента с ЯВНОЙ позицией order ничего не делает: */
.d { grid-column: 3; grid-row: 1; order: 99; }

Порядок в HTML: A B C D E F → визуально получилось: C A B D E F

Важные ограничения order:

  • действует только на авто-размещение — элемент с явным grid-column/grid-row (урок 3) стоит на месте;
  • элементы с одинаковым order идут в исходном порядке HTML;
  • из HTML-потока ничего не исчезает — для скринридеров и «честного» кода порядок остаётся как в разметке.
⚠️ Напоминание из урока 4: элемент с margin: auto и явной позицией тоже выходит из потока авто-размещения — браузер «ставит его сразу», и это сдвигает места последующих элементов.

4Дыры и back-filling: dense

Когда элемент шире, чем место в текущей строке, он «перепрыгивает» на новую строку, а позади остаётся дыра. Обычный поток (row flow) дыру не заполняет — курсор только идёт вперёд: 

.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: repeat(3, 56px);
  gap: 8px;
}

.b, .d { grid-column: span 2; } /* B и D — двойная ширина */

/* C (ширина 1) в обычной раскладке — во 2-ю строку, дыра на (1,4).
       С dense он «откатывается» назад и заполняет её: */
.grid-dense { grid-auto-flow: row dense; }

С grid-auto-flow: dense браузер заглядывает назад и ставит узкие элементы в первые свободные ячейки — C занял бы (1,4), E — (2,4). Обратная сторона: визуальный порядок больше не совпадает с порядком в HTML.

⚠️ dense — инструмент для плотных раскладок (галереи, дашборды, канбан). Для контентных страниц с логическим порядком (карточки товара, шаги, статьи) оставьте обычный row flow — дыра лучше, чем «перепрыгивающие» элементы.
