Строки и области сетки

Урок 2: grid-template-rows, именованные области grid-template-areas и сокращение grid-template

1Свойство grid-template-rows

В уроке 1 мы описали только колонки, а строки создавались автоматически по мере заполнения сетки. Но у Grid есть полная симметрия: свойство grid-template-rows работает так же, как grid-template-columns, — только для строк.

Список значений задаёт высоту каждой строки в том же порядке — сверху вниз:

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 колонки */
  grid-template-rows: 72px 110px;        /* 1-я строка 72px, 2-я — 110px */
  gap: 12px;
}

Правила те же, что и для колонок:

  • Допустимы те же значения: px, %, fr, auto, minmax(), repeat();
  • Если элементов больше, чем строк в шаблоне, лишние строки создаются имплицитно с высотой auto (по содержимому);
  • Очень часто строки вообще не описывают и дают им auto — тогда высота каждой строки определяется самым «высоким» элементом в ней.
💡 fr в строках работает так же, как в колонках, только по вертикали: grid-template-rows: 1fr 2fr — вторая строка вдвое выше первой. Именно так делают «шапка — контент — подвал»: auto 1fr auto.

2Сокращение grid-template

Если нужны и строки, и колонки, их можно описать одним свойством grid-template — сначала строки, затем колонки, разделитель — /: 

/* раздельно */
grid-template-rows: 64px 1fr 64px;
grid-template-columns: 240px 1fr;

/* то же самое, короче */
grid-template: 64px 1fr 64px / 240px 1fr;

Обратите внимание: порядок — строки / колонки. Это легко запомнить: «сначала сверху-вниз, потом слева-направо».

⚠️ Важно: grid-template сбрасывает и grid-template-rows, и grid-template-columns, поэтому не дублируйте их, если используете сокращение.

3Именованные области: grid-template-areas

Самая удобная функция Grid — описывать макет «картинкой». Свойство grid-template-areas позволяет нарисовать сетку строками текста, где каждое слово — имя области: 

.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 64px 1fr 64px;
  grid-template-areas:
    "header header"
    "sidebar content"
    "footer footer";
  gap: 10px;
}

/* каждый элемент привязывается к области одним свойством */
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer  { grid-area: footer; }

Как это читается: каждая строка шаблона — одна строка сетки, каждое слово — одна ячейка. Одно и то же имя, повторённое в строке, растягивается на все эти ячейки (так header занимает обе колонки).

Шапка grid-area: header
Сайдбар grid-area: sidebar
Контент grid-area: content
Подвал grid-area: footer

Особенности синтаксиса областей:

  • Порядок элементов в HTML не важен — место задаётся именем области;
  • Точка . — пустая ячейка: "content .";
  • Область может занимать несколько ячеек, но только прямоугольником;
  • Имена — простые идентификаторы: header, main, ad-top (чертой можно);
  • Элемент с grid-area, которого нет в шаблоне, размещается автоматически — проверяйте опечатки!

4Попробуйте: перестройте макет без HTML

Главная сила именованных областей — перестановка блоков меняя только CSS. HTML ниже один и тот же, меняется только grid-template-areas (и размеры): 

<div class="layout">
  <header class="header">Шапка</header>
  <aside class="sidebar">Сайдбар</aside>
  <main class="content">Контент</main>
  <footer class="footer">Подвал</footer>
</div>

💡 Обратите внимание: в «журнальном» макете точка . создаёт пустую ячейку — сетка сохраняет форму 2×3, но одна ячейка свободна. Именно так делают сложные редакционные макеты и дашборды.

5Итоги урока

СвойствоГде задаётсяЧто делает
grid-template-rows контейнер Количество и высоты строк (значения — те же, что для колонок)
grid-template контейнер Сокращение: строки / колонки; сбрасывает оба свойства выше

✅ Правило практики: для крупных макетов страницы используйте grid-template-areas — код читается как схема, а перестройка (сайдбар влево/вправо, мобильная одна колонка) делается одной строкой CSS внутри media query.
