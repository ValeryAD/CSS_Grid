Выравнивание элементов и контейнера

Урок 4: как элементы «плывут» в своих ячейках (justify-* / align-*) и как сама сетка располагается в контейнере (place-content), плюс трюк с margin: auto

1Почему элементы «растягиваются» и откуда берутся оси

По умолчанию элемент Grid растягивается на всю свою ячейку (stretch) — в отличие от обычного потока, где блок сам решает, какой ему быть. Чтобы изменить поведение, Grid даёт четыре свойства-пары — по одному на каждую ось:

  • Горизонталь (ось колонок) — justify-*;
  • Вертикаль (ось строк) — align-*;
  • «одним словом» — place-* (сокращение обеих осей).

У каждой пары есть два уровня действия: на элемент внутри его ячейки и на всю сетку внутри контейнера. Разберём оба.

Вот четыре значения выравнивания по горизонтали — одно в каждой колонке:

💡 Запоминалка: justify = «справедливо по горизонтали», align = «вертикально». Если запутались — подумайте: текст выравнивают по оси (justify-content: space-between у колонок), а строки — по линиям (align-content).

2Элементы в ячейках: justify-items, align-items, place-items

Свойства задаются контейнеру (display: grid) и влияют на все его элементы: 

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 96px);
  gap: 10px;

  /* по горизонтали и по вертикали — по центру ячеек */
  place-items: center;

  /* то же самое, но по отдельности: */
  /* justify-items: center;  — по горизонтали */
  /* align-items:   start;   — по вертикали   */
}

/* у одного элемента — своя позиция, перекрывает общее */
.card { align-self: start; justify-self: end; }

Полный набор «на элемент»:

  • justify-self / align-self — один конкретный элемент;
  • justify-items / align-items — все элементы контейнера;
  • place-items — сокращение обоих (place-items: center = оба по центру);
  • значения: stretch (по умолчанию), start, end, center;
  • бонус: baseline — выровнять текст разных элементов по базовой линии.
⚠️ justify-items/align-items влияют только на то, как элемент сидит в своей ячейке. Если трексы 1fr, свободного места «на выравнивание» почти нет — используйте их вместе с фиксированными размерами элементов (как в плейграунде ниже).

3Сетка в контейнере: justify-content, align-content, place-content

А если трексы имеют фиксированные размеры, а контейнер больше, чем вся сетка? Появляется свободное пространство вокруг трексов — и его распределяют свойства justify-content (горизонталь) и align-content (вертикаль): 

.grid {
  display: grid;
  grid-template-columns: repeat(3, 120px); /* фикс. размеры — условие! */
  grid-template-rows: repeat(2, 72px);
  gap: 12px;
  height: 340px; /* контейнер больше, чем сетка */

  justify-content: space-evenly; /* по горизонтали */
  align-content: space-evenly;   /* по вертикали   */

  /* или одной строкой: */
  /* place-content: space-evenly; */
}

Значения justify-content / align-content:

  • start — вся сетка прижата к началу (по умолчанию — «top left»);
  • end — к концу;
  • center — по центру свободной зоны;
  • space-between — трексы прижаты к краям, всё свободное — между ними;
  • space-around — отступы вокруг каждого трека, на краях — вдвое меньше;
  • space-evenly — одинаковые отступы везде.
💡 Ключевое отличие от items: content-свойства двигают трексы целиком (вместе с элементами), а items-свойства двигают элементы внутри своих ячеек. space-* работают только когда трексы не растягиваются на всё пространство — то есть не fr до краёв.

4margin: auto — «суперсила» Grid

В Grid автоматические отступы работают иначе, чем в обычном потоке: margin: auto съедает всё свободное место в пределах области элемента. Это самый удобный способ центрировать или смещать один конкретный элемент: 

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 88px);
  gap: 10px;
}

/* элемент 2: занимает 2 колонки и прижат к правому краю области */
.plain {
  grid-column: 2 / 4;
  justify-self: end;
}

/* элемент 4: блок с фиксированной шириной — по центру своей области */
.auto {
  grid-column: 1 / 4;
  width: 220px;
  margin-inline: auto; /* = margin-left + margin-right: auto */
}

/* тот же приём, но по обеим осям сразу: */
/* .center { margin: auto; } */

Живой пример — ровно эта сетка: синяя плашка занимает две колонки и прижата к правому краю (justify-self: end), а зелёный блок шириной 220px по центру своей области «висит» благодаря margin-inline: auto:

a
justify-self: end
c
margin-inline: auto
⚠️ Важно: из потока авто-размещения элемент выходит, когда у него есть явное grid-column (или grid-row / grid-area) — как у двух элементов выше. Само по себе margin: auto размещение не влияет — оно лишь «съедает» свободное место в уже выделенной области. Как явное размещение сочетается с grid-auto-flow, разберём в уроке 5.

Когда что использовать:

  • «все элементы по центру ячеек» — place-items: center;
  • «один элемент — в другой угол, остальные как обычно» — align-self/justify-self;
  • «вся сетка по центру/в конец контейнера» — place-content;
  • «один широкий блок по центру своей области» — margin-inline: auto (работает даже когда область шире самого блока).
