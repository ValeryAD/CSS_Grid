Гибкость и адаптивный макет

Урок 7 (финальный): почему фиксированные колонки ломаются на узких экранах, minmax() как двигатель адаптивности, auto-fit vs auto-fill, clamp()/min()/max(), сборка responsive-макета и живое демо ресайза

1Фиксированная сетка перестаёт работать

Все наши демо — от «3 колонки» (урок 1) до карточек (урок 6) — использовали константы: 1fr 1fr 1fr, 88px 1fr, repeat(3, 1fr). Это отлично работает, пока экран достаточно широк. Но на узком контейнере три «ровные» колонки превращаются в три сплющенные щели: 

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* всегда ровно 3 колонки */
}

⚠️ Точки роста сетки — две вещи, которые мы до сих пор держали фиксированными: ширина трека и количество треков. В этом уроке снимаем оба ограничения — и получаем адаптивный макет без единой медиазаписи.

2minmax() — двигатель гибкости

Функция minmax(min, max) задаёт треку разрешённый диапазон ширины: «не уже min, не шире max». В сочетании с 1fr она означает: раздай лишнее пространство по-честному, но ни за что не сжимай трек ниже моего минимума: 

.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(140px, 1fr));
  /* каждая колонка: от 140px до «сколько влезет, по-честно» */
  /* если влезает только 1 такая колонка — остальные треки уйдут вниз (урок 5) */
}

Оба контейнера ниже одинаковой ширины. Слева минимум 110px — три таких трека не помещаются, и сетка вылезает за рамку (а при auto-flow — «упадёт» во второй ряд). Справа минимум 70px — три колонки вписываются:

💡 minmax() — это «гибкость с гарантией»: трек растягивается, когда есть место, и защищается, когда места мало. Именно она делает repeat(auto-fit, …) таким популярным.

3auto-fit и auto-fill: сколько треков создавать

Пока что repeat() всегда получал фиксированное число: repeat(3, …). Grid умеет и другое — repeat(auto-fit, …) и repeat(auto-fill, …): «создай столько треков, сколько влезает при заданном минимуме». Разница между ними видна только когда элементов меньше, чем треков: 

/* auto-fit — пустые треки схлопываются в 0 */
.fit  { grid-template-columns: repeat(auto-fit, minmax(80px, 1fr)); }

/* auto-fill — пустые треки остаются, просто пустыми */
.fill { grid-template-columns: repeat(auto-fill, minmax(80px, 1fr)); }

В контейнер влезает 4 трека по 80px, а элементов всего два. auto-fit схлопывает два пустых трека — карточки занимают всю ширину. auto-fill держит все 4 трека — и вы видите два пустых «слота»:

auto-fit — 2 элемента растягиваются на всю ширину
1
2
auto-fill — 4 трека, 2 из них пустые
1

Когда что:

  • auto-fit — почти всегда: галереи, карточки, плитки. Меньше элементов → они становятся шире, макет «дышит»;
  • auto-fill — когда важна геометрия: календари, плитки-иконки, слоты «под будущие элементы». Пустые ячейки должны оставаться видимыми;
  • при переполнении (элементов больше, чем треков) оба работают одинаково: лишние уходят в новые строки (урок 5).

4clamp(), min(), max() — плавные значения

minmax() работает с треками, но та же идея — «значение с ограничителями» — существует и для любых CSS-значений: 

/* clamp(минимум, «желаемое», максимум) */
h1 { font-size: clamp(1rem, 4vw, 2.5rem);
       /*  не меньше 1rem, не больше 2.5rem,
          а между — 4% ширины окна: текст «течёт» плавно  */
}

/* min() и max() — те же ограничители по одному краю */
.sidebar { width: min(30vw, 320px);  /* 30% окна, но не шире 320px */ }
.badge   { width: max(80px, 12cqi);  /* 12% контейнера, но не уже 80px */ }

Тяните правый нижний угол контейнера ниже — заголовок плавно растёт и упирается в максимум, а карточка тянется за контейнером, но останавливается на 380px:

Плавный заголовок: clamp(1rem, 9cqi, 2.4rem)

Карточка: width: min(90%, 380px)
💡 cqi — 1% ширины контейнера (container queries, включённые свойством container-type). Можно заменить на vw (1% ширины окна) — принцип тот же: значение растёт вместе со средой, но держится в коридоре. clamp() — главный инструмент «флюидной типографики»: без него адаптивность упирается в резкие ступеньки медиазаписей.

5Сборка responsive-макета

Собираем «страницу» целиком — и не пишем ни одной @media. Каркас — сетка с minmax() на сайдбаре (урок 2, области), а карточки внутри — auto-fit: 

.page {
  display: grid;
  gap: 10px;
  grid-template-columns: minmax(150px, 240px) 1fr;
  /* сайдбар: от 150 до 240px — шире уже не растёт */
  grid-template-areas:
    "top   top"
    "side  main"
    "cards cards";
}

.page .cards {
  grid-template-columns: repeat(auto-fit, minmax(90px, 1fr));
  /* сколько карточек влезает — столько и колонок */
}

✅ Обратите внимание на разделение ответственности: minmax() на треках каркаса задаёт диапазон сайдбара, а repeat(auto-fit, minmax(…)) в карточках решает сколько их поместится. Три свойства — и макет адаптируется от телефона до широкоэкранного монитора.
