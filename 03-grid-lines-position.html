Линии сетки и позиционирование

Урок 3: как устроены линии Grid, longhand-свойства grid-*-start/grid-*-end, шорткаты grid-column / grid-row и grid-area, span, отрицательные номера и именованные линии

1Из чего состоит сетка: линии и ячейки

Ключевое понятие Grid — линия (grid line). Сетку образуют линии колонок (вертикальные) и линии строк (горизонтальные). Ячейка (grid cell) — это прямоугольник, заключённый между соседними линиями по обоим измерениям. Элементы Grid размещаются не «по ячейкам», а между линиями — от линии к линии.

Линии пронумерованы: для сетки из N колонок существует N + 1 вертикальных линий — от 1 до N + 1. Счёт с конца идёт через отрицательные числа: -1 — последняя линия.

1 2 3 4 5
1 2 3
(1,1)
(2,1)
(3,1)
(4,1)
(1,2)
(2,2)
(3,2)
(4,2)

На схеме — сетка 4 колонки × 2 строки: 5 вертикальных и 3 горизонтальных линии. Подсвечена ячейка между линиями 2→3 по колонкам и 1→2 по строкам.

💡 Частая ошибка: «поставить элемент в 2-ю колонку» — это grid-column: 2 / 3 (от линии 2 до линии 3), а не grid-column: 2. Один номер — это не позиция, а одна линия: элемент растянулся бы по всей сетке.

2Позиционирование элементов: от longhand к shorthand

У каждого элемента в сетке четыре «границы»: стартовая и конечная линия по колонкам, стартовая и конечная по строкам. Зафиксировать элемент можно четырьмя свойствами по отдельности (longhand), шорткатами grid-column / grid-row или одним grid-area.

2.1 Longhand-свойства: по одной линии на границу

Самый «детальный» способ записи — четыре свойства: grid-column-start, grid-column-end, grid-row-start, grid-row-end. Каждое задаёт только одну линию, остальные остаются auto по умолчанию: 

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 70px);
  gap: 8px;
}

/* четыре свойства — по одному на границу элемента */
.b {
  grid-column-start: 2;    /* левая граница: от 2-й линии колонок */
  grid-column-end: 4;    /* правая граница: до 4-й линии колонок */
  grid-row-start: 2;     /* верхняя граница: от 2-й линии строк */
  grid-row-end: 3;      /* нижняя граница: до 3-й линии строк */
}

/* span и отрицательные номера работают здесь так же */
.b {
  grid-column-start: 2;
  grid-column-end: span 2;   /* вширь на 2 колонки вправо */
  grid-row-start: 1;
  grid-row-end: -1;        /* от первой до последней линии строк */
}
cell (1,1)
cell (2,1)
cell (3,1)
cell (1,2)
B: четыре линии по отдельности
cell (3,2)

Когда longhand удобен:

  • нужно изменить только одну границу: «растянуть вправо до края» — grid-column-end: -1, а всё остальное не трогаем;
  • подправляем позицию в медиазапросе: переписать одну линию понятнее, чем весь шорткат;
  • смешиваем с именованными линиями: grid-column-start: sidebar-end (раздел 3).

2.2 Шорткаты: grid-column и grid-row

Свойства grid-column и grid-row задают обе линии одной оси разом — линию старта и линию финиша: 

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 70px);
  gap: 8px;
}

/* вариант 1: линия старта / линия финиша */
.b { grid-column: 2 / 4; }   /* занимает 2-ю и 3-ю колонки */

/* вариант 2: линия старта + количество ячеек (span) */
.b { grid-column: 2 / span 2; } /* то же самое, читается проще */

/* вариант 3: отсчёт с конца через -1 */
.b { grid-column: 2 / -1; }   /* от 2-й линии до последней */

/* только span — место выберет браузер автоматически */
.b { grid-column: span 2; }

То же самое работает по строкам — grid-row. Пример на живой сетке 3×2:

cell (1,1)
cell (2,1)
cell (3,1)
B: grid-column: 1 / 4

Варианты записи, которые нужно знать:

  • 2 / 4 — от линии 2 до линии 4 (2 колонки);
  • 2 / span 2 — от линии 2, вширь на 2 колонки;
  • span 2 — «вширь на 2 колонки», где поместится — туда;
  • 2 / -1 — от линии 2 до последней линии;
  • auto — браузер выбирает сам (по умолчанию).

2.3 grid-area: все четыре линии одним свойством

grid-area — самый большой шорткат: он задаёт все четыре линии сразу. Порядок значений жёсткий: сначала строки, потом колонки — row-start / column-start / row-end / column-end: 

/* строки 1→3, колонки 2→4 */
.b { grid-area: 1 / 2 / 3 / 4; }

/* то же самое, longhand-свойствами: */
.b {
  grid-row-start: 1;
  grid-column-start: 2;
  grid-row-end: 3;
  grid-column-end: 4;
}

/* span и -1 работают и в grid-area */
.b { grid-area: 1 / 2 / span 2 / -1; }

Другое лицо grid-area — именованные области, с которыми мы встретились в уроке 2: grid-area: sidebar — это удобный способ записать сразу четыре линии области. Одно свойство — и элемент «прикручен» к макету.

⚠️ Ловушка порядка: в grid-area строки идут до колонок, а в grid-column: 2 / 4 оба значения — про колонки. Поэтому grid-area: 2 / 1 / 3 / 4 означает «строки 2→3, колонки 1→4», а не наоборот.

Иерархия шорткатов — от детального к компактному:

  • grid-column-start/end, grid-row-start/end — четыре линии по отдельности;
  • grid-column / grid-row — пара линий (старт / финиш) для одной оси;
  • grid-area — все четыре линии сразу, либо именованная область.
⚠️ Элемент с явным grid-column/grid-row или grid-area «выходит из потока» авто-размещения — остальные элементы занимают оставшиеся места. Об этом поговорим в уроке 5 (grid-auto-flow).

3Именованные линии

Как и области (урок 2), линии можно называть. Имя ставится в квадратные скобки перед значением, к которому относится линия. Так шаблон читается как схема макета: 

.layout {
  display: grid;
  grid-template-columns:
    [sidebar-start] 240px
    [sidebar-end content-start] 1fr
    [content-end];
}

.sidebar { grid-column: sidebar-start / sidebar-end; }
.content { grid-column: content-start / content-end; }

Обратите внимание: одна и та же линия может носить несколько имён ([sidebar-end content-start]) — так «стыкуются» соседние зоны. Имена линий — обычный идентификатор: можно использовать в любом grid-column, grid-row и grid-area.

Именованные линии vs именованные области:

  • grid-template-areas (урок 2) — нагляднее для целых блоков макета и адаптации;
  • именованные линии — гибче, когда нужно точечно управлять размером элемента (например, «от линии X до конца»);
  • оба подхода можно смешивать: области ссылаются на линии и наоборот.

4Перекрывание элементов

Grid — единственная встроенная система, где элементы могут перекрывать друг друга: достаточно задать пересекающиеся линии. Это удобно для карточек с оверлеем, «прилипших» подписей, модальных окон внутри макета. 

/* сетка 3 × 3 */
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(3, 60px);
  gap: 8px;
}

.a { grid-column: 1 / 3; grid-row: 1 / 3; } /* левый верхний квадрат 2×2 */
.b { grid-column: 2 / 4; grid-row: 2 / 4; } /* правый нижний квадрат 2×2 */
a: 1/3, 1/3
b: 2/4, 2/4

Порядок наложения — как в обычном потоке: элемент, который дальше в HTML, оказывается сверху. Если нужно изменить, используйте z-index (для этого у элемента должен быть контекст наложения — в Grid это работает «из коробки»).
