CSS Grid — основы

Урок 1: что такое Grid, первый пример и свойство grid-template-columns

1Что такое CSS Grid?

CSS Grid — система раскладки, позволяющая организовать элементы страницы по двум измерениям одновременно: по строкам и по столбцам. В отличие от Flexbox, который работает в одном измерении (ряд или колонка), Grid создаёт полноценную двухмерную сетку.

Ключевые преимущества:

  • Двумерная раскладка — строки и столбцы одновременно;
  • Размер ячеек определяется сеткой, а не содержимым (и наоборот, если нужно);
  • Возможность позиционировать элементы по линиям сетки и перекрывать их;
  • Код раскладки описывается в CSS и отделён от разметки;
  • Отлично сочетается с media query и адаптивным дизайном.
💡 Совет: Grid и Flexbox не конкуренты, а дополняют друг друга. Grid — для общей структуры страницы (макет), Flexbox — для мелких компонентов внутри ячеек (навигация, карточки).

2Первый пример: три колонки

Чтобы создать сетку, нужно сделать два шага: назначить контейнеру display: grid и описать колонки через grid-template-columns. 

/* HTML */
<div class="grid">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
  <div>5</div>
  <div>6</div>
</div>

/* CSS */
.grid {
  display: grid;
  grid-template-columns: 100px 100px 100px; /* три колонки по 100px */
  gap: 12px; /* расстояние между ячейками */
}

💡 Свойство gap задаёт расстояние между строками и столбцами — это современный аналог устаревшего grid-gap.

3Свойство grid-template-columns

grid-template-columns определяет, сколько будет колонок и какая у каждой ширина. Каждое значение в списке — это одна колонка, значения разделяются пробелом: 

grid-template-columns: col1 col2 col3 ...;

В качестве ширины колонки допустимы разные типы значений:

ЗначениеПримерЧто означает
Абсолютные единицы 200px, 12em, 2rem Фиксированная ширина колонки
Проценты 50%, 33.3% Доля от ширины контейнера
Дроби — fr 1fr, 1fr 2fr Доля свободного места. 1fr 2fr — вторая колонка вдвое шире первой
Ключевое слово auto Ширина по содержимому ячейки
Функция repeat(3, 1fr) Повторяет шаблон: 3 равные колонки по 1fr
Функция minmax(100px, 1fr) Ширина не меньше 100px и не больше 1fr
Адаптивные repeat(auto-fit, minmax(150px, 1fr)) Сколько влезет колонок шириной от 150px — ровно столько и создаётся

Типичные комбинации:

/* 3 равные колонки */
grid-template-columns: 1fr 1fr 1fr;
grid-template-columns: repeat(3, 1fr); /* то же самое, короче */

/* боковые колонки фиксированные, средняя — растягивается */
grid-template-columns: 200px 1fr 200px;

/* колонки 1:2:1 — средняя вдвое шире крайних */
grid-template-columns: 1fr 2fr 1fr;

/* адаптивная сетка карточек: от 150px, сколько влезет */
grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
💡 fr против %: 100% — это всегда доля всего контейнера, даже если соседние колонки «забирают» место. 1fr — доля только свободного места, оставшегося после распределения фиксированных колонок.
