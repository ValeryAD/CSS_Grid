Вложенность (Nesting)

Урок 6: grid внутри grid, grid и flexbox рядом, почему длинные строки «раздувают» ячейки и как чинить это через min-width: 0, практика — карточки с внутренними сетками

1Grid внутри grid

Любой элемент сетки может сам стать контейнером Grid. Вложенная сетка «изолирована»: её строки, колонки и gap не связаны с родительской — каждый контейнер независимо вычисляет свои треки. Это главный приём для карточек, плиток и дашбордов: 

.cards {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 16px;
}

/* каждая карточка — САМОСТОЯТЕЛЬНАЯ сетка */
.cards > article {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 8px;
}

.cards > article .title {
  grid-column: 1 / -1;   /* заголовок — на всю ширину (урок 3) */
}

💡 Свойства не «протекают» через вложенность: gap, треки и выравнивание родительской сетки ничего не наследуют внутрь вложенной. Свободная комбинация: grid в grid, grid в flex, flex в flex — выбирайте под задачу.

2Grid и Flexbox: когда что

Оба раскладывают элементы, но flexbox — одномерный (раздаёт элементы вдоль одной линии: строка или колонка), а Grid — двумерный (строки и колонки одновременно). Поэтому в одном макете они прекрасно сочетаются:

  • Flexbox — «хлебные» ряды: шапка карточки (заголовок + кнопка), тулбары, списки, меню;
  • Grid — матрицы: сетка статистики, календари, галереи, сложные карточки с фото и метаданными.
.report {
  display: grid;
  grid-template-rows: auto 1fr;
}

/* шапка: одномерный ряд → flexbox */
.report-head {
  display: flex;
  justify-content: space-between;  /* урок 4 */
  align-items: center;
}

/* тело: матрица из 3 ячеек → grid */
.report-body {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

3Раздувание ячеек и min-width: 0

Самая частая «поломка» вложенных сеток: у grid-элемента есть автоматический минимальный размер (min-content) — треку 1fr нельзя стать уже, чем минимальное содержимое. Если внутри лежит длинная непереносимая строка (URL, API-токен, монокод), она «раздувает» трек, и вся сетка вылезает за контейнер: 

.list {
  display: grid;
  grid-template-columns: 1fr 1fr;
}

/* БЕЗ фикса: длинный токен шире контейнера → сетка вылезает */

/* ФИКС: разрешить элементу сжиматься */
.list > .item {
  min-width: 0;         /* снять автоматический min-size */
  overflow: hidden;    /* или одна эта строка тоже сработает */
}
без min-width: 0 — строка шире пунктирного контейнера

Как чинить раздувание:

  • min-width: 0 на grid-элементе — снимает автоматический минимальный размер;
  • overflow: hidden (или auto) — автоматически делает min-size равным 0, плюс обрезает вылезшее;
  • если текст должен быть виден целиком — дайте ему переноситься: overflow-wrap: anywhere;
  • тот же эффект есть и у flex-элементов (min-width: auto по умолчанию) — фикс одинаковый.

4Практика: карточки с внутренними сетками

Собираем карточку профиля из всего, что прошли: внешняя сетка раскладывает карточки (урок 1), внутренняя — grid-template-areas (урок 2), а тег-чипы — ещё одна вложенная сетка: 

.profiles { display: grid; grid-template-columns: 1fr 1fr; }

.profile {
  display: grid;
  grid-template-columns: 88px 1fr;
  grid-template-areas:
    "photo title"
    "photo meta"
    "tags  tags";
  gap: 12px;
}

/* и третья сетка — внутри карточки */
.profile .tags {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
